# 新しい出力デバイスへの取り付けを、画面から行えるようにする

## 目的・背景

APO は出力デバイスごとに取り付ける。インストーラは、入れた時点で Windows にあるデバイスにだけ取り付ける。
あとからつないだヘッドホンなどにはツマミが効かず、画面にも何も出ない。直すにはインストーラをやり直すしかない。

これを「アプリが知らせ、ボタンを 1 回押せば効く」にする。

## 対応方針

### 動き

1. 画面のアプリが、いまの既定の出力デバイスを 2 秒ごとに調べる
2. そのデバイスに APO が付いていなければ、画面の上の端に「〈デバイス名〉には、まだ効きません」と「効くようにする」ボタンを出す
   - 新しく見つけたときは、トレイに隠れているウィンドウを前に出して知らせる（デバイス 1 つにつき、アプリの起動中に 1 回だけ）
3. ボタンを押すと、インストール先に置いてある登録のスクリプト（`apo\install-apo.ps1 -AllDevices`）を管理者として起動する。Windows の確認（UAC）が出る
4. スクリプトが終わったら、もう一度調べて表示を消す。音のサービスの再起動で、音が一度止まる

### 作り

- `app/src-tauri/src/devices.rs`（新しく作る）
  - 既定の出力デバイスの ID を Windows に尋ねる（COM の `IMMDeviceEnumerator`）
  - そのデバイスの `FxProperties` に、この APO の CLSID があるかをレジストリで調べる（読むだけ。管理者でなくてよい）
  - APO そのものが登録されているか（CLSID のキーがあるか）も調べる。入っていないときは、取り付けではなくインストーラでの入れ直しを案内する
  - 登録のスクリプトを管理者として起動し、終わるのを待つ（`ShellExecuteExW` の `runas`）
- 画面: 上の端の知らせにボタンを足す。処理中はボタンを押せなくする
- APO の DLL、登録のスクリプトは変えない

### 取り付けられない場合

- 確認（UAC）で「いいえ」を押した: 何も変えず、知らせを残す
- ドライバが古い形式で効果を登録していて、段が埋まっているデバイス: スクリプトは取り付けない。終わっても付いていないので、「このデバイスには取り付けられません」と表示する
- インストーラで入れていない版（試すための `equalizer.exe`）: スクリプトが無いので、その旨を表示する

## 影響範囲

- `app/`（Rust と画面）。依存するクレートに `windows` と `winreg` を足す
- インストーラの作り直しが要る。APO の DLL の入れ替えは要らない

## テスト方針

- 「値に CLSID が含まれるか」の判定は、単体テストで確かめる
- sx360: 既定の出力デバイスから APO を外した状態を作り（ユーザーが開発用のスクリプトで行う）、知らせが出ること、ボタンで付くこと、UAC を断ったときに何も変わらないことを確かめる

## 結果（2026-11-20）

- 作った。「値に CLSID が含まれるか」の単体テストは通る
- 「あとからつないだデバイス」の状態を作るために、開発用のスクリプト `apo/scripts/detach-default-device.ps1` を足した
- sx360 で、ユーザーがインストーラで入れ、既定の出力デバイスから APO を外して確かめた。「問題ない」との確認
- 試せていないこと: 取り付けられないデバイス（段が埋まっているもの）での表示。sx360 にそういうデバイスが無い
