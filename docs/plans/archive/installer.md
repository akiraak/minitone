# 使う人向けのインストーラを作る

## 目的・背景

いまは開発用のスクリプトを管理者の PowerShell で動かして入れている。
公開するアプリとして、1 つのファイルを実行すれば入り、Windows の「インストールされているアプリ」から外せるようにする。

## 対応方針

### 方式

Tauri の標準のインストーラ（NSIS）を使う。`setup.exe` が 1 つできる。

- 画面のアプリ（`equalizer.exe`）を `C:\Program Files\equalizer` に置く。スタートメニューへの登録、アンインストーラ、「インストールされているアプリ」への登録は、Tauri の標準の機能
- APO の登録と解除は、動作を確かめてある `apo/scripts/install-apo.ps1` と `uninstall-apo.ps1` をそのまま同梱し、インストーラのフック（インストールの後、アンインストールの前）から呼ぶ
  - 登録の処理を別の言語で書き直さない。sx360 で実際に動かした処理を使う
- インストーラは管理者の権限で動く（全ユーザー向けのインストール）。APO の登録に管理者の権限が要るため

### 気を付ける点

- NSIS のインストーラは 32 bit のプロセス。そこから普通に PowerShell を起動すると 32 bit 版が動き、レジストリの書き込み先が 32 bit 用の場所にずれる。64 bit 版の PowerShell を明示して呼ぶ（`Sysnative`）
- 上書きインストールのときは、音のエンジンが古い DLL を読み込んでいる。`install-apo.ps1` は、音のサービスを止めて置き換える処理を既に持っている
- インストーラには署名が無い。実行時に Windows の SmartScreen の警告が出る

### 要るツール

- Tauri の CLI（バージョン 2）。sx360 に入っているのはバージョン 1.5.12 で、インストーラの形式が合わない
  - ほかのプロジェクトに影響しないよう、全体には入れず、このプロジェクトの作業フォルダ（`%LOCALAPPDATA%\akiraak-equalizer-dev\tools`）にだけ入れる
  - NSIS 本体は、Tauri の CLI が初回に自分で取ってくる
  - ツールを入れるので、ユーザーに確認してから行う

### Step

1. 設定とフックを書く（Tauri の設定、NSIS のフック、同梱するファイル）
2. Tauri の CLI を入れ、インストーラをビルドする
3. sx360 で確かめる: 開発用に入れてあるものを外す → インストーラで入れる → 音が変わる → 「インストールされているアプリ」から外す → 元に戻る
4. README を、インストーラでの入れ方に直す

### このプランに含めないもの

- 新しい出力デバイスへの取り付けを、画面から行う機能（別のタスク）
- Windows の起動時に自動で立ち上げる設定
- インストーラへの署名

## 影響範囲

- `app/src-tauri/tauri.conf.json`、新しいフックのファイル、ビルドのスクリプト、README
- sx360: Tauri の CLI を作業フォルダに入れる。確認のために、APO の解除と登録をやり直す（ユーザーが実行）

## テスト方針

- インストールとアンインストールを sx360 で実際に行い、レジストリを入れる前の控えと比べる
- 上書きインストール（入っている状態でもう一度入れる）も確かめる

## 結果（2026-11-20）

- Step 1〜4 を終えた。Tauri の CLI 2.12.6 を作業フォルダに入れ、インストーラをビルドした
- インストール: アプリは `C:\Program Files\equalizer` に入り、APO は 64 bit 側のレジストリに登録され、出力デバイス 12 個に付いた（`Sysnative` 経由で 64 bit 版の PowerShell を呼ぶ対処が効いている）
- 上書きインストール: 入っている状態の上から入れて、動作に問題が無いことをユーザーが確かめた
- アンインストール: 1 回目は、値が 9 個残った。原因は、登録のスクリプトが「自分が新しく作った値」の記録を、登録をやり直すたびに上書きしていたこと
  - 直した内容: 記録を積み上げる（`CreatedValues`）。記録が無くても、このスクリプトが作ったと分かる値（この APO だけの MFX の値と組になった、既定のモードだけの指定）は見分けて消す
  - 直した版を入れてから外すと、残っていた 9 個も消えた。出力デバイスの `FxProperties` の値は 773 個で、入れる前の控えと一致した（このアプリが触っていない値 2 個は、ドライバか Windows が書き換えていた）
  - `DisableProtectedAudioDG`、COM と APO の登録、ファイル、「インストールされているアプリ」の登録も、入れる前の状態に戻った
- あわせて直したこと: レジストリの控え（1 回で約 6 MB）を登録のたびに書き出していたのを、入っていない状態から入れるときだけにした
- アンインストールしても残すもの: `C:\ProgramData\akiraak-equalizer`（設定、ログ、控え）
