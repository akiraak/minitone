# Equalizer APO を sx360 に入れて動作を確かめる

## 目的・背景

音の処理を Equalizer APO に任せると決めた（[技術選定](tech-selection.md)）。
アプリを作り始める前に、sx360 で実際に効くかを確かめる。特に、既定の出力が Bluetooth のヘッドホンであること、Windows 11 25H2 での動作が公式に明言されていないことが気がかり。

## 対応方針

インストールとアンインストールは管理者の権限と再起動が要るので、**ユーザーが実行する**。Claude Code は手順を示し、前後の状態を読み取りで確かめる。

### Step 1: 入れる前の状態を控える

- Claude Code が、出力デバイスごとの APO の登録（レジストリの `FxProperties`）を読み取って控える（リポジトリの外に置く。デバイスの ID を含むのでコミットしない）
  - 2026-11-19 完了。WSL の `~/equalizer-backup/` に、出力デバイスのレジストリを書き出した
- 任意: ユーザーが復元ポイントを作る（システムの保護が有効な場合）

### Step 2: 入れる（ユーザーが実行）

1. [SourceForge](https://sourceforge.net/projects/equalizerapo/files/) から `EqualizerAPO-x64-1.4.2.exe` を落として実行する
2. 途中で出るデバイスの選択画面で、使う出力デバイス（本体のスピーカー、Bluetooth のヘッドホン、ディスプレイの音声）にチェックを入れる。接続していない機器が一覧に出るかをここで見る
3. 再起動する

### Step 3: 確かめる

- 音が今までどおり出るか（スピーカー、Bluetooth のヘッドホン）
- 設定ファイルに目立つフィルタ（例: `Preamp: -20 dB`）を書き、すぐ音が変わるか
- 設定ファイルからフィルタを消すと、元の音に戻るか
- 出力デバイスを切り替えても、何も操作せずに効くか
- 設定ファイルの置き場所と、管理者でなくても書き換えられるか（アプリが昇格なしで書けるかが決まる）
- 接続していない Bluetooth の機器を先に登録できるか
- 動画の音ずれ、通話（Hands-Free）のときの挙動

### Step 4: 結果を書く

- 結果をこのファイルに書き、アプリの作りに関わること（設定ファイルの場所、未登録のデバイスの見つけ方）を `CLAUDE.md` に書く
- うまく動かないときは、下の「元に戻す手順」で戻し、次の案（仮想デバイスに出してアプリで処理する）を検討する

## 元に戻す手順

軽い順に試す。

1. **フィルタを切る**: 設定ファイル（`config.txt`）の中身を空にする。Equalizer APO は入ったまま、音は素通しになる
2. **デバイスから外す**: スタートメニューの「Equalizer APO」→「Device Selector」（旧名 Configurator）で、そのデバイスのチェックを外して再起動する
3. **アンインストールする**: Windows の「設定」→「アプリ」→「インストールされているアプリ」から Equalizer APO を外して再起動する
4. **音が出ないままのとき**: デバイス マネージャーでそのオーディオ デバイスを「デバイスのアンインストール」してから再起動し、ドライバを入れ直させる。復元ポイントを作ってあれば、そこへ戻す

2〜4 は管理者の権限が要る。3 でデバイスの登録が入れる前の状態に戻るかは、Step 1 で控えた内容と比べて確かめる。

## 影響範囲

- sx360 の Windows 側の音の経路（選んだ出力デバイスに APO が付く）
- リポジトリは、このプランと `CLAUDE.md`、`TODO.md` だけ

## テスト方針

- Step 3 の項目を、ユーザーの耳と、Claude Code の読み取り（レジストリ、設定ファイル）の両方で確かめる

## 中止（2026-11-19）

Step 1 まで行ったところで中止した。使う人がこのアプリだけを入れれば使えるようにするため、Equalizer APO を使わず自前の APO を作ると決めた（[プラン](../custom-apo.md)）。
Step 1 で控えたレジストリの書き出し（`~/equalizer-backup/`）は、自前の APO を試すときの「入れる前の状態」としてそのまま使う。
