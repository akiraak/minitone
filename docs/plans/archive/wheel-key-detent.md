# まんなかから、ホイールと矢印キーで動かないのを直す

## 目的・背景

2026-11-20、曲線の表示を作っているときに Claude がコードを読んで気づき、ユーザーが「直して」と指示した。

値がまんなか（BASS、MID、TREBLE は 0 dB、VOLUME は 100%）にあるとき、ホイールや矢印キーで 1 刻み動かしても、値が変わらなかった。ツマミ、バー、グラフの点のどれでも同じ。

原因: `app/ui/main.js` の `snap` が、まんなかから 1 刻み以内の値を、いつもまんなかに戻していた。これはツマミのドラッグで、まんなかに止まりやすくするための処理。ホイールとキーは 1 回で 1 刻みしか動かさないので、まんなかから出られなかった。

## 対応方針

- まんなかに止める処理を、ツマミのドラッグのときだけにする（`snap` と `change` に `sticky` を足す）。
- ホイール、矢印キー、PageUp / PageDown は、止めずに 1 刻みずつ動かす。BASS などは ±0.5 dB、VOLUME は 99%、101% にもできるようになる。
- バーとグラフの点のドラッグは、もともと別の処理（まんなかの 3 px 以内）なので、変えない。

## 影響範囲

- `app/ui/main.js` だけ。

## テスト方針

- 画面のファイルをヘッドレスの Edge で開き、まんなかの値からホイールと矢印キーのイベントを送って、表示の値を読む。
  - 直す前: どれも 0.0 dB、100% のまま（再現した）。
  - 直したあと: 1 刻みずつ動く。ツマミのドラッグは、いままでどおり、まんなかの近くで止まり、通り抜けられる。
- `app/build.ps1` が通ること。

## 結果（2026-11-20）

直した。上の確かめ方で、ホイールは +0.5 → +1.0 → 0.0 dB、矢印キーは −0.5 dB、+0.5 dB、101%、99% と動いた。ツマミのドラッグは、3 px（0.55 dB）では 0.0 dB のまま、11 px では +2.0 dB。ビルドとテストも通った。
