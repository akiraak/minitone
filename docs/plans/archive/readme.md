# README を書く

## 目的・背景

公開のリポジトリなのに、README が「開発を始めたところ」の 1 行のままになっている。
このアプリは Windows の署名の検査を切るなど、入れる人が先に知っておくべき副作用がある。

## 対応方針

- 何をするアプリか、いまの完成度、仕組み、入れると変わるもの、ビルドと入れ方、戻し方、制約を書く
- 確かめていないこと（解除で完全に元へ戻るか、DRM 付きの再生）は、確かめていないと書く
- 日本語で書き、冒頭に英語の短い説明を残す

## 影響範囲

- `README.md` だけ

## テスト方針

- 書いたコマンドとパスが、リポジトリのスクリプトと一致することを確かめる

## 結果（2026-11-19）

- 書いた。コマンドとパスはスクリプトと照らし合わせた
