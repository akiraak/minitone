# 表示の切り替えを、右の端からツマミの上に移す

## 目的・背景

2026-11-20 にユーザーが指示した（原文「ツマミぶぶんの表示切替が右にあるけど、つまみの上部に移動する。デザインを作成してそこから決める」）。

いまの切り替えは、右の端のまんなかに縦に並べた 3 つの小さい絵（ツマミ、バー、曲線）。ウィンドウは 688 x 190 で、ツマミの列（ツマミ 116 px、名前、値）が高さをほぼ使い切っているので、上に置くには、高さを足すか、ツマミを小さくする必要がある。

## 対応方針

### Step 1: デザイン案を 5 つ作る（2026-11-20、済み）

画面のファイルの写しに CSS だけを足し、ヘッドレスの Edge に 3 つの表示を描かせた。値は BASS +6.0 dB、MID +2.0 dB、TREBLE −3.0 dB、VOLUME 100%。絵はコミットしない（非公開の Artifact のページに置いた）。

どの案も、右の端の列が無くなり、右の空きは左と同じ 22 px。電源のボタンはウィンドウの高さのまんなか。

- P1: ツマミの上に 20 px の帯を足し、右に寄せて絵を横に 3 つ。ウィンドウは 654 x 210。
- P2: P1 と同じ帯で、絵をツマミの並びのまんなかに。654 x 210。
- P3: 絵をやめて文字のタブ（KNOBS、BARS、CURVE）。BASS の上から左にそろえる。654 x 210。
- P4: P2 の絵を、丸い枠で 1 つにまとめる。654 x 210。
- P5: 高さは 190 px のまま、ツマミを 116 → 100 px にして上に帯を作る。絵は右。590 x 190。グラフも同じ割合で小さくなる。

気づいたこと: 上の端に出る知らせ（"Not active on … yet."、高さ 26 px）は、出ている間、切り替えに重なる。

### Step 1 の続き: P4 のバランスを見直した案（2026-11-20、済み）

ユーザーが「P4が一番イメージに近い。バランスを見直したデザインをいくつか作って」と指示。5 つ作り、同じページの上に足した。どれも幅 654 px で、ツマミ、バー、グラフの大きさはいまと同じ。

- P4-1: 帯を 20 → 26 px に広げる（654 x 216）。枠の上が 9 px。枠の大きさと場所は P4 のまま。
- P4-2: 絵 1 つぶんを 34 → 42 px 幅にし、いまの表示の後ろに明るい地を付ける。帯は 30 px（654 x 220）。
- P4-3: P4-1 の枠を、VOLUME の列の右の端にそろえる。
- P4-4: P4-1 の枠を、BASS の列の左の端にそろえる。
- P4-5: 帯とツマミの間に、彫った溝の横線を入れる。帯は 32 px（654 x 222）。

### Step 2: ユーザーが案を選ぶ（2026-11-20、済み）

ユーザーが「P4-3 で実装して」と決定。

### Step 3: 選ばれた案で作る（2026-11-20、済み。ユーザーが実物を見て「問題ない」と確認）

- `app/ui/style.css`: 上に 26 px の帯を足し（body の上の余白 14 → 40 px）、切り替えを帯の右（右の端から 22 px、上から 9 px）に、丸い枠で囲んで横に並べた。右の端の列を無くした（バーの右の余白 56 → 22 px）。電源の列は帯の半分（13 px）だけ上げ、ウィンドウの高さのまんなかにした。縦線は上の端から 8 px のまま。
- `app/src-tauri/tauri.conf.json`: ウィンドウを 688 x 190 → 654 x 216。
- README の絵 3 枚を作り直し、切り替えの場所の説明を直した。CLAUDE.md の画面の説明を直した。
- 確かめたこと: 画面のファイルをヘッドレスの Edge に描かせ、3 つの表示とも案 P4-3 のとおりで崩れていないことを絵で見た。`app/build.ps1` が通った。そのあと、ユーザーが実物で確かめた。

## 影響範囲

- 画面のアプリ（`app/ui/`、ウィンドウの大きさ）。APO、設定ファイル、Rust 側の処理は変えない。
