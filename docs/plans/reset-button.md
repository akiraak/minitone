# ツマミのリセットボタンを入れる

## 目的・背景

- 2026-11-20 にユーザーが指示:「ツマミのリセットボタンを入れる」。着手のときに「デザインを 5 つ作って」。
- いまは、ツマミをダブルクリックすると、そのツマミだけがまんなか（0 dB、100%）に戻る。まとめて戻す手段は無い。

## 対応方針

- Step 1: デザイン案を 5 つ作る（済み）。絵は、いまの画面の HTML と CSS から作った 1 枚のページ（コミットしない。ユーザーの「ダウンロード」フォルダに置いた）。値は BASS +6.0 dB、MID +2.0 dB、TREBLE −3.0 dB、VOLUME 125%。
  - A: 右の端に、丸い押しボタン。電源のボタンと同じ形で、ひと回り小さい（直径 40 px）。ウィンドウの幅を 730 → 800 px に広げる。
  - B: 電源のボタンの下に、小さい四角のキー。電源のボタンは少し上に寄る。ウィンドウの大きさは変えない。
  - C: 右上の隅に、文字だけの小さいボタン。ウィンドウの大きさは変えない。上の端の知らせが出ている間は隠れる。
  - D: ツマミごとに、値の横の小さい矢印。押したツマミだけが戻る。ウィンドウの大きさは変えない。
  - E: 右下の隅に、丸い矢印のボタン（直径 24 px、文字なし）。ウィンドウの大きさは変えない。
- Step 1 の続き: ユーザーが「power ボタンの周辺にスペースがあるのでそこに配置するデザイン例を 5 つ作って」と指示（2026-11-20）。電源のボタンの周りに置く案を 5 つ足した（済み）。ウィンドウの大きさは、どれも変えない。
  - F: 電源のボタンの上に、"RESET" の文字の小さいボタン（枠つき）。
  - G: 電源のボタンの上に、丸い矢印のボタン（直径 24 px、文字なし）。
  - H: 電源のボタンの右下に寄りそう、小さい丸いボタン（直径 22 px、文字なし）。
  - I: 電源のボタンと "POWER" の文字の間に、"RESET" と書いた四角いキー。
  - J: 電源のボタンを少し上に寄せ、"ON" の下に "RESET" の文字の小さいボタン（枠つき）。
- Step 2: ユーザーが案を選ぶ。どのツマミを戻すか（BASS、MID、TREBLE だけか、VOLUME も含むか）もここで決める。
- Step 3: 選ばれた案で作る。

## 影響範囲

- 画面のアプリ（`app/ui/`）。A の案なら、ウィンドウの幅（`app/src-tauri/tauri.conf.json`）と README の画面の絵、CLAUDE.md の画面の大きさも変わる。
- APO、設定ファイルの書式、登録と解除のスクリプトは変えない。
- 画面の文は英語だけ（"RESET"）。

## テスト方針

- Step 3 で `app/build.ps1` が通ること。
- ユーザーが「ダウンロード」フォルダの `MiniTone.exe` で、ボタンを押すとツマミが戻り、音も戻ることを確かめる。
