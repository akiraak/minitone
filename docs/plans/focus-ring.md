# ツマミの周りのオレンジの丸を出さない

## 目的・背景

- 2026-11-20 にユーザーが報告: ツマミを操作したあとにキーボードの音量調整を行うと、ツマミの周りにオレンジの丸が表示される。
- 2026-11-20 にユーザーが指示:「表示しないようにする」。
- オレンジの丸は、フォーカスのあるツマミを示す枠（`app/ui/style.css` の `.knob:focus-visible` の outline）。マウスで操作したツマミにフォーカスが残り、そのあとキーを押すと（音量のキーも含む）、WebView がキーボードの操作とみなして枠を出す。

## 対応方針

- `#power:focus-visible` と `.knob:focus-visible` の outline を `none` にする。電源のボタンも同じ仕組みで枠が出るので、合わせて消す。
- ルールを消すだけだと WebView の既定の枠が出るので、`outline: none` を明示する。
- 知らせの「Enable」ボタン（`#attach`）の白い枠は、そのままにする。

## 影響範囲

- `app/ui/style.css` だけ。
- Tab キーでツマミや電源のボタンに移ったときも、どれを選んでいるかの枠が出なくなる。キーボードでの操作（矢印キーなど）そのものは変わらない。

## テスト方針

- `app/build.ps1` でビルドし、「ダウンロード」フォルダの `MiniTone.exe` でユーザーが確かめる: ツマミをマウスで回したあと、キーボードの音量のキーを押して、オレンジの丸が出ないこと。
