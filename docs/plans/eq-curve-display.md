# 3 つめの表示（イコライザーの曲線の画面）を作る

## 目的・背景

2026-11-20 にユーザーが指示した（原文「３つ目の表示画面を作る。イコライザー表示でよくある画面にして、低中高音の各ポイントを上下できるものにする。ボリュームはツマミにする」）。

いまの表示は、アナログ（ツマミ）とデジタル（LED のバー）の 2 つ。これに、横が周波数、縦が増減（dB）のグラフの表示を足す。

## 対応方針

- グラフの上に BASS、MID、TREBLE の 3 つの点を置き、上下にドラッグして値を変える。VOLUME はツマミのまま、グラフの横に置く。
- 動かせるのは上下（増減）だけ。周波数（150 Hz、2 kHz、5 kHz）と Q は固定で、点は左右に動かせない。
- 値の範囲と刻みは、いまと同じ（±20 dB、0.5 dB 刻み、VOLUME は 0〜150%）。3 つの表示は同じ値を見る。RESET も同じように効く。
- ウィンドウの大きさ（688 x 190）、電源のボタン、RESET、縦線は変えない。
- 表示の切り替えの絵は、右の端に縦に 3 つ（ツマミ、バー、曲線）。どの表示かは、いまと同じ localStorage（`minitone.view`）に覚える。

### Step 1: デザイン案を 5 つ作る（2026-11-20、済み）

絵は実物と同じ大きさ。値は BASS +6.0 dB、MID +2.0 dB、TREBLE −3.0 dB、VOLUME 125%。点は絵の上でドラッグできる。絵はコミットしない（ユーザーの「ダウンロード」フォルダの `minitone-curve-designs.html` と、非公開の Artifact のページに置いた）。

- G1: 実際の曲線（フィルタを計算した形）。横は周波数（20 Hz〜20 kHz）。点は 150 Hz、2 kHz、5 kHz の位置、設定の値の高さ。線は点を通らないので、点と線を点線でつなぐ。
- G2: 実際の曲線。黒い窓に入れ、線の下を塗る。BASS の点は 50 Hz、TREBLE の点は 12 kHz（線がほぼ設定の値に届く、平らなところ）。
- G3: 点と線だけ。等間隔の 3 本の縦の溝に点があり、まっすぐな線でつなぐ。名前と数字は溝の下。
- G4: なめらかな線。等間隔の 3 つの点を通る線を、黒い窓に入れる。名前と数字は点の下。線は実際の音の形ではない。
- G5: G2 の形で、VOLUME のツマミを 116 → 84 px にしてグラフを広げる。数字は下の 1 行。フィルタごとの形を暗い線で重ねる。

### Step 1 の続き: 曲線の後ろに棒グラフを入れた案（2026-11-20、済み）

ユーザーが「ハードウェアのイコライザーは棒グラフがいくつも並んでる形になってるよね。今の曲線グラフの背景に棒グラフを描画して」と指示。棒の高さは、その周波数での曲線の高さ。線の下の塗りはやめた。同じページの上に足した。

- H1: G2 の形に、LED の棒を 20 本（1 粒 2 dB）。まんなか（0 dB）から上下に光る。
- H2: H1 の棒を、下の端から曲線の高さまで光らせる。
- H3: 太い棒を 10 本。粒に分けず、まんなかから曲線の高さまで塗る。
- H4: G1 の形（点は 150 Hz、2 kHz、5 kHz）に、H1 の棒。
- H5: G4 の形（等間隔のなめらかな線）に、H1 の棒。

### Step 2: ユーザーが案を選ぶ（2026-11-20、済み）

ユーザーが「H2 で実装して」と決定。

### Step 3: 選ばれた案で作る（2026-11-20、済み。ユーザーが実物を見て「問題ない」と確認）

- `app/ui/index.html` に、グラフ（`#curve`、392 x 164 の SVG）と 3 つめの切り替えの絵（`#view-curve`）を足した。BASS、MID、TREBLE のツマミの場所にグラフが入り、VOLUME のツマミはそのまま。
- `main.js`: 線は、APO（`Dsp.cpp`）と同じ式を 48 kHz で計算して描く。`setupKnob` が、ツマミ、バー、グラフの点の 3 つに同じ操作を付ける。
- 点の操作は、点をつかんで上下に動かす形にした（Claude の判断。ユーザーは指定していない）。つかんだ場所が点のまんなかから外れていても、点は飛ばない。0 dB の線の 3 px 以内は 0 dB。
- どの表示かは、いままでと同じ localStorage（`minitone.view`）に `curve` として覚える。Rust 側と設定ファイルは変えていない。
- 確かめたこと: `app/build.ps1`（テストとビルド）が通った。画面のファイルを、Tauri の代わりの見せかけの値（BASS +6、MID +2、TREBLE −3、VOLUME 125%）でヘッドレスの Edge に描かせ、3 つの表示とも崩れていないことを絵で見た。そのあと、ユーザーが実物で確かめた。

## 影響範囲

- 画面のアプリ（`app/ui/`）だけ。APO、設定ファイルの書式、Rust 側、登録と解除のスクリプトは変えない。
- 画面の文は英語だけ。

## テスト方針

- `app/build.ps1` が通ること。
- ユーザーが sx360 で、3 つの表示を切り替えられること、どの表示でも値が合っていて音が変わること、切り替えを覚えていることを確かめる。
